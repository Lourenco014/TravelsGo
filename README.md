# 🌎 TravelsGo

TravelsGo é uma landing page responsiva desenvolvida para uma empresa fictícia especializada em gerenciamento de viagens. O projeto foi criado com o intuito de melhorar minhas habilidades como programador front-end.

## ✨ Funcionalidades

* Layout totalmente responsivo;
* Navegação intuitiva;
* Apresentação dos serviços da empresa;
* Design moderno e profissional;
* Compatibilidade com dispositivos móveis, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## 🎯 Objetivos do Projeto

* Praticar desenvolvimento Front-End;
* Aprimorar técnicas de responsividade;
* Trabalhar organização e estruturação de interfaces;
* Desenvolver uma experiência visual agradável para o usuário.

## 📱 Responsividade

A aplicação foi construída seguindo princípios de design responsivo para garantir uma navegação consistente em diferentes resoluções de tela.

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd TravelsGo
```

3. Abra o arquivo `index.html` em seu navegador.
